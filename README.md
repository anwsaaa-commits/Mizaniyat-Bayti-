# ميزانية بيتي

تطبيق Android مستقل لإدارة ميزانية المنزل والمشتريات اليومية، باللغة العربية وواجهة RTL، مع تخزين محلي يعمل دون اتصال بالإنترنت.

## الهوية التقنية
- Flutter / Dart
- Package ID: `com.alshaheen.homebudget`
- Project name: `mizaniyat_bayti`
- قاعدة بيانات محلية SQLite
- العملة الافتراضية: الريال اليمني (ر.ي)

## مراحل التطوير
1. تأسيس المشروع، الهوية البصرية، ونواة الحسابات والاختبارات.
2. قاعدة البيانات وإدارة الدخل والمصروفات والفواتير والتصنيفات.
3. الميزانيات والتنبيهات ولوحة المؤشرات والتقارير.
4. تصدير PDF وExcel/CSV والمشاركة والنسخ الاحتياطي والاستعادة.
5. مراجعة الأمان، اختبار البيانات، وبناء APK إصدار Release.
